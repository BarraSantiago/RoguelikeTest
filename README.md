\# \*\*Basic Survivors – README\*\*



A \*\*roguelike survivors\*\* mobile game for Android built with Unity. You control a hero from a \*\*top-down perspective\*\*, survive endless waves of enemies, and progress through both temporary and permanent upgrades.



---



\## \*\*Gameplay\*\*



Move using a \*\*virtual joystick\*\* while your attacks are performed automatically, targeting the nearest enemy. Each run challenges the player to survive as long as possible while enemies scale over time (+20% stats per minute).



Leveling up grants random upgrade choices that can modify damage, attack speed, projectile count, area, range, cooldown reduction, and more.



Core actions:



\* \*\*Automatic basic attack\*\*

\* \*\*Special attack\*\* with a longer cooldown

\* \*\*Defensive ability:\*\* knockback (Warrior) or dodge (Ranger)



When the player dies, the run ends and earned coins can be spent on permanent upgrades.



---



\## \*\*Classes \& Progression\*\*



\*\*Base Classes:\*\*



\* \*\*Warrior:\*\* Melee-focused combat

\* \*\*Ranger:\*\* Ranged projectile combat



\*\*Unlockable Subclasses:\*\* Berserker, Paladin, Reaver, Sniper, Hunter, Trapper.



\*\*Two layers of progression:\*\*



\* \*\*Run-based:\*\* level-up upgrades, power-ups, temporary stat boosts.

\* \*\*Permanent:\*\* shop upgrades, achievements, new subclasses.



---



\## \*\*Enemies \& Effects\*\*



Enemy types:



\* \*\*Normal\*\*

\* \*\*Elite\*\* (2× health, 1.5× damage)

\* \*\*Boss\*\* (4× health, 1.5× damage)



Status effects: \*\*Slow\*\*, \*\*Root\*\*, \*\*Knockback\*\*.

Collectibles: \*\*experience orbs\*\* and \*\*coins\*\*.
